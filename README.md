# My Wallet

미국 여행용 동전 지갑이에요. 받은 동전과 지폐를 세어 두고, 금액과 팁을 넣으면 어떤 지폐와 동전을 내면 되는지 알려줘요.

- 동전·지폐 개수 관리, 결제 계산, 팁 계산
- 결제 내역(날짜별), 여행 기간 설정과 귀국 2일 전 동전 소진 알림
- 한 번 열어 두면 인터넷 없이도 열려요. 홈 화면에 추가하면 앱처럼 쓸 수 있어요.
- 입력한 내용은 각자의 휴대폰 브라우저에만 저장돼요.

동전 이미지: 오픈소스 앱 Coin Collection(anwilli5/coin-collection-android-us)에 포함된 미국 조폐국 동전 이미지.
